# API Test Case Matrix

74 requests with 137 fixed assertions, plus 14 validation-matrix rows. Generated by `npm run build` from `src/build-collection.js`. Cases marked **KNOWN-BUG** assert the correct behaviour and currently fail by design (see [defects](defects)).

**Why reports say more assertions than this table:** the 3 data-driven requests (DD-01 to DD-03, 7 assertions) run once for each of the 6 data rows, and the validation request (VAL-01) runs once for each of 14 rows. A full run therefore executes 130 + 7 x 6 + 14 = 186 assertions.
