# BUG-017: Chosen sort order is lost after viewing a product

| Field | Value |
|---|---|
| Severity | Minor |
| Priority | Low |
| Module | Sorting |
| Origin | Genuine |
| Status | Open |
| Found in | https://www.saucedemo.com, Chrome (Chromium), 2026-11-05 |
| Test user | `standard_user / secret_sauce` |
| Failed test cases | TC-080 |

## Steps to reproduce
1. Log in and choose Price (high to low)
2. Open any product
3. Click Back to products

## Expected result
The list is still sorted high to low.

## Actual result
The sort resets to Name (A to Z).

## Evidence
Browser alert or behaviour with no screenshot; reproduce with the steps above.

> Impact if real: shoppers must re-sort after every product they open. Logged as if found in a real product. The practice shop has no server behind its login, so this is how it is built, but a real shop with this behaviour would have the stated impact.
